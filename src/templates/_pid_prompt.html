⬆️ PiD ×4 — prompt de reconstruction

PiD reconstruit l'image en 4 étapes, conditionnée par le prompt. Un prompt-recette (« garde le sujet, redessine… ») est une instruction, pas une description du contenu — le résultat partira dans la mauvaise direction. Écrivez ce que vous voyez.

⚠️ Ce prompt ressemble à une instruction d'édition — adaptez-le à ce que vous voyez, ou lancez avec la description générique.
